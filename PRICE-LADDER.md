# Price ladder playbook ($9-$29)

## Principles (short)

1. **Charm endings:** $9 / $19 / $29 read as "under the next ten"; $12 / $27 feel deliberate and "kit-like."
2. **Anchor up, then offer the middle:** show $29 (or Bundle $27) near a $12-$19 offer so the middle looks fair.
3. **One job per price:** don't sell two products at the same price unless one is clearly a bundle.
4. **Bundle math must be honest:** Bundle price < sum of parts (e.g. $19 + $12 = $31 -> Bundle $27).
5. **Never fake scarcity** or invent "was $X" unless you actually sold at that price.

## When to use each point

### $9 - impulse / tip-jar adjacent
- Single checklist, one-pager, or sample CSV.
- Goal: first purchase + email trust, not margin.
- Avoid for anything that took days to build.

### $12 - low-friction utility
- Clear, complete job-to-be-done (e.g. invoice + 3 reminder emails).
- Buyer should finish in one sitting.
- Great "first dollar" SKU.

### $19 - core single product
- Spreadsheet + short guide + samples.
- Feels like a real kit, not a tip.
- Default for Cashflow / Seller Ledger-style tools.

### $27 - bundle / "starter system"
- 2-3 related files that people already buy separately.
- Headline: "everything to start X" not "discount dump."
- Ideal after $12 + $19 exist so savings are real.

### $29 - premium / ops-heavy
- Multi-template workflows (proposal -> SOW -> kickoff).
- Optional launch price $24 for first week only if you will raise to $29.
- Pair with a thank-you upsell to a finance SKU, not another $29.

## Ladder examples

**Finance path:** $12 Invoice -> $19 Cashflow -> $27 Bundle
**Ops path:** $19 Cashflow -> $29 Client Ops
**Seller path:** $19 Seller Ledger -> $27 Tax Dashboard (later)

## Anti-patterns

- Pricing everything at $19 (no ladder, no upgrade path).
- Bundle more expensive than buying parts.
- $9 for a 40-page PDF (undervalues; buyers distrust).
- Changing price daily (hurts reviews and trust).
