# gumroad-price-psychology-notes

Practical pricing notes for digital downloads on Gumroad/Etsy.

## Ladder we use

| Price | Role |
|------:|------|
| $9–$12 | Impulse / add-on (Invoice Pack) |
| $19 | Core hero (Cashflow Kit) |
| $27 | Bundle value (show savings vs à la carte) |
| $29 | Premium ops pack (Client Ops) |

## Rules of thumb
- Anchor the bundle against sum of parts ($19+$12=$31 → $27).
- Don’t launch hero under $15 (cheap-junk signal).
- Raise after 5+ sales/reviews, not before.
- Coupons: prefer $5 off once, not 50% forever.
