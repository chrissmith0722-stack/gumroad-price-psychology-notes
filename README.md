# gumroad-price-psychology-notes

Markdown playbook for pricing digital downloads on Gumroad (and similar) at **$9 / $12 / $19 / $27 / $29**.

Not financial advice. No payment APIs. Copy ideas into your listings.

## Files

| File | Purpose |
|------|---------|
| `PRICE-LADDER.md` | When to use each price point + ladder examples |
| `COPY-SNIPPETS.md` | Anchoring, charm pricing, and bundle framing lines |
| `LICENSE` | MIT |

## Quick ladder (freelancer finance stack)

| Price | Role | Example SKU |
|------:|------|-------------|
| $9 | Impulse / lead magnet adjacent | Mini checklist or sample pack |
| $12 | Low-friction utility | Invoice + Reminder Pack |
| $19 | Core single kit | Cashflow Kit / Seller Ledger |
| $27 | Bundle / "complete" feel | Finance Starter Bundle |
| $29 | Premium ops / higher perceived effort | Client Ops Kit |
